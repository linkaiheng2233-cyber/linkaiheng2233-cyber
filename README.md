# supermumu

我在做 **A.I.Live（OCLive）**：让创作者自由制作 AI 角色，让角色在本地运行；也给开发者一组可替换的 Rust 能力契约，去构建自己的 Host。

Building **A.I.Live (OCLive)**: local-first AI character experiences, a small Rust contract library, and tools for role creators.

## 从这里开始

| 你想做什么 | 入口 |
|---|---|
| 了解项目、体验角色 | [A.I.Live 主仓库](https://github.com/linkaiheng2233-cyber/oclivenewnew) · [五分钟介绍](https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/human-docs/START_HERE.md) |
| 创作自己的角色包 | [角色包编写器](https://github.com/linkaiheng2233-cyber/oclive-pack-editor) |
| 使用小内核、编写模块或 Host | [OCLive Kernel](https://github.com/linkaiheng2233-cyber/oclive-kernel) |
| 在编辑器里和角色聊天 | [OCLive VS Code](https://github.com/linkaiheng2233-cyber/oclive-vscode) |
| 看硬件陪伴原型 | [实体角色宿主计划](https://github.com/linkaiheng2233-cyber/oclive-skippy-plan) |

A.I.Live 仍在开发与内测。各仓的源码版本、已有安装包与在研计划分别标注；下载前请看对应 Release 说明。主仓和独立内核使用 Apache-2.0，工具与角色素材的许可看各自仓库。
